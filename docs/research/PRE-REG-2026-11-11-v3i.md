# PRE-REGISTRATION — v3i (2026-11-11), written before v3i is trained

## Arm
v3i seed 0 = v3 seed 0's recipe exactly (data `awlike_full_v3,awgen_v3`, 1,824 steps x 16, lr 1e-5, warmup 30, frozen
embedding, image width 720, base `LiquidAI/d1-2B@cfe5760`, the 5090 host and environment), with ONE change: on a fixed
half of the rows (`ac_common.instruction_included`: sha256("ep:step")[0] < 128) the state carries AndroidControl's
low-level step instruction (`local_goal`) as a `Step instruction:` line right after the goal. Generator rows and the
terminal `status` rows have no instruction and are unchanged. Contract name `v3i` (= v3 + `instruction`).

Why: (1) a checkpoint that can be scored on AndroidControl-Low as well as High; (2) the instruction names the element
("Click on the Send button"), i.e. extra grounding supervision on the same screens, the weakest part of v3 (AC-High
grounding 67.7%).

## Evaluation (fixed now)
Final checkpoint (ckpt_1824), no checkpoint selection.
* `validation_v3` without instruction: steps right, goals with every step right.
* AC-High (InfiGUI scorer, 8,444 steps, standard: every action allowed): SR / type / grounding.
* AC-Low: same, with `--instruction` (each step's own instruction).
* AndroidWorld: only if the kill rule below passes; served without instruction.

## Comparison: v3 seed 0 final checkpoint
validation_v3 63.4% steps, 14/137 goals; AC-High SR 67.10%, type 80.97%, grounding 67.70%.

## Kill rule (one seed; v3's seed spread on this data is not measured, earlier programme sd ~2 points)
* v3i is NOT used for AndroidWorld if, without instruction, AC-High SR < 66.1 (v3 − 1.0) or validation_v3 steps
  < 62.4% (v3 − 1.0).
* A gain on AC-High below +2.0 SR points is reported as "not distinguishable from seed noise".

## Predictions (mechanism)
1. AC-Low SR far above AC-High SR (the instruction states the action and usually the element).
2. AC-High grounding up (more element-level supervision), type roughly unchanged.
3. Risk: the model leans on the instruction; without it, validation_v3 and AC-High fall (the kill rule catches it).
