# Status — 2026-11-08 early morning

## The result that survived a full day of retractions — with a correction to its significance

**Duplicating the training decisions to 22,500 rows raises grounding by +2.62 points. This is suggestive, NOT
certified: the equal-variance test that first reported p < 0.05 does not apply to this data (§ corrected 2026-11-08).**

| recipe | seeds | grounding | sd | distinct values |
|---|---|---|---|---|
| `cur15k` (15,000 rows) | 3 (s0, s1, s2) | **56.80%** | 1.29 | 2 (125/223, 130/223) |
| **`ctrl22k` (15k duplicated to 22,500)** | **4 (s0, s2, s3, s4)** | **59.42%** | **0.45** | 2 (132/223, 134/223) |

Each arm has only **two distinct values** (grounding is a count out of 223), so its sd is a floor estimated from one
contrast, and the variance ratio is **8.3×**. The three defensible tests disagree:

| test | statistic | p |
|---|---|---|
| Student pooled (equal variance — **assumption violated**) | t = 3.84, df = 5 | 0.012 |
| Welch (unequal variance) | t = 3.34, df = 2.4 | **0.063** |
| exact permutation (35 partitions; min attainable p) | most extreme arrangement | 0.029 |

**Do not quote "p < 0.05" for this.** The pre-registered bar was t ≥ 2.78 at **5 seeds per recipe**; only 3 and 4
exist. Placement-only measure (`grounded given type`) moves **64.85% → 68.86% (+4.02)** across all seven seeds;
spatial type accuracy pays **1.27 points**.

**Two findings, not one:**
1. the duplicate recipe is **higher** (+2.62), and
2. it is **2.9× more stable** (sd 0.45 vs 1.29) — three consecutive seeds gave *exactly* 59.19%.

**What the lever actually is**, stated so it cannot be misread: both recipes run 938 steps × 16 = **15,008 samples**;
every run logs `epoch: 0`. The duplicate arm draws those samples from a longer list, so it **never revisits a row
within the run**, while the baseline wraps at the end. It is *a clean pass over a larger list*, **not more data** —
no new examples exist and the gradient-step count is identical.

**Cost:** zero at inference. Both arms are 720 px; measured per-row p50 is **99.5 ms (15k, 3-seed mean)
vs 97.1 ms (22.5k, 4-seed mean)** — equal within run-to-run variation.
