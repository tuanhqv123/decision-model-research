DMA-2B: one forward pass per phone action

DMA-2B is a 2B decision model for Android agents. At each step it reads the screenshot, the goal, what it has done so far and the list of on-screen elements, then chooses the next action from fixed options and the element to act on. It writes no text, so every output can be executed, and every choice has a probability. Below are three AndroidWorld tasks it completed, replayed step by step from our evaluation run (model on a GPU, about 130 ms per decision).

    How to read this page
    

    Action probabilities: the probability the model gave to each kind of action at this step (they sum to 1).
Element probabilities: for click, type and answer, which element of the list it picks (for open app: which app; for scroll: which direction); the red box is the chosen
element and the circle is where the tap lands (the element's centre). Done ends the episode; AndroidWorld's
checker then reads the phone's state to decide whether the task was completed.
